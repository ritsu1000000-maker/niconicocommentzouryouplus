コメント増量は、ニコニコ動画のコメント数を増量、及び全コメ表示がブラウザ上で出来る拡張機能です。

## インストール
1.[リリースページより](https://github.com/tanbatu/comment-zouryou/releases)Source code (zip)をダウンロード、 展開する。

2.Chromeで「<strong>chrome://extensions</strong>」にアクセスする。

3.右上のデベロッパーモードをオンにして, 「<strong>パッケージ化されていない拡張機能を読み込む</strong>」を選択し、 1.でダウンロードしたフォルダを選択する。

## v8.2 の追加機能
### 並列取得(高速化)
- 1つのスレッドを投稿日時で区間に分け、複数の区間を同時に遡って取得します(コメントは投稿直後に集中するので、区間は投稿日側を細かく切っています)。
- 通常・投稿者・かんたんコメントの各スレッドと、引用した動画も同時に取得します。
- ページ境目で同じ秒に投稿されたコメントを取りこぼさないよう1秒重ねて取得し、コメ番で重複を除きます。
- 並列といっても上限は下記の安全ペースのままで、通信の待ち時間を重ねることで速くしています。

### 回数制限(429)を避ける安全ペース
- 制限に当たってから待つのではなく、最初から「間隔1秒以上・1分50回まで」に固定して取得し、制限に当たらないようにしています。
- この回数は localStorage に記録し、再読み込み・別タブ・連続実行でも合算して守ります(続けて読み込んでも上限を超えません)。
- 上限に届きそうなときは自分で待ち、ログに「待機中…」と表示します。
- 設定は安全側にしか変えられません(同時接続1〜4、間隔1000〜5000ms、1分1〜60回)。より遅くしたいときは間隔を長く・上限を小さくしてください。
- 万一429が返った場合だけ、指定秒数待って同時接続数を1にします(保険)。
- 期限切れのthreadKeyは、並列中でも1回だけ再取得します。

### コメント検索・統計(「検索・統計」ボタン)
- キーワード検索: スペースでAND、`|`でOR、`-`で除外。正規表現・完全一致・表記ゆれ無視(全角半角/カタカナひらがな/大小文字)。
- 検索対象: 本文・コマンド・ユーザーID・すべて。
- 詳細条件: 再生位置の範囲(現在位置±30秒ボタンあり)、投稿日の範囲、ニコる数、文字数、通常/投稿者、プレミアムのみ、NG適用後のみ。
- 並び替え: 再生位置・新しい/古い投稿・ニコる・コメ番・長さ。
- 結果をクリックでその位置へシーク。ユーザーIDクリックで同じユーザーのコメント一覧。コピー・NG追加ボタン。
- 「検索結果だけを描画」で、ヒットしたコメントだけを動画上に流せます。
- 検索結果をCSV(Excel対応)・JSON・テキストで書き出し。
- 統計タブ: 取得数・ユニークユーザー数・期間、盛り上がりグラフ(クリックでシーク)、盛り上がりシーン上位、投稿数の推移、よく使われるコメント/コマンド、コメントが多いユーザー。

### 軽量描画
- 描画設定の「軽量描画」をONにすると、再生位置1秒あたりのコメント数を上限(既定40件)まで間引いて描画し、30fpsを上限にします。
- ニコるが多いコメントを優先して残します。一覧・検索・書き出しは全件のままです。
- 「コメントアートが崩れないようにする」がONなら、複数行のコメントは間引きません。

### コメントアートだけ残す
- 描画設定の「コメントアートだけ残す」をONにすると、コメントアートと判定したコメントだけを描画します(通常・投稿者コメントとも。間引きはしません)。
- 判定: 複数行のコメント／CA用コマンド(ender・full・patissier)／罫線・ブロック・点字などの記号が多い／上下固定+大きさ指定で記号を含む長めのコメント。
- 検索の詳細条件にも「コメントアートのみ」を追加しました。

### その他
- コメントリストの行をクリックでその位置へシーク。
- NGリストの表示をHTMLとして解釈しないように修正(コメント本文からNG追加しても安全)。

## 注意
大量のコメントを処理する為、コンピューターのスペックによってはフリーズする恐れがあります。
